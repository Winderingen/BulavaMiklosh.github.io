# 📋 Генератор отчетов на повышение (СБП ФСО)

Веб-сервис для автоматического формирования отчетов на присвоение очередного воинского звания в СБП ФСО.

## ✨ Особенности

- ✅ **4 отдела**: ОБО, ЦСН, Академия ФСО, АС (Административная Служба)
- ✅ **Полные системы повышения** для каждого отдела (до 8 уровней)
- ✅ **Автоматическая подстановка** желаемого звания (+1 ступень)
- ✅ **Отдельные поля** для каждой ссылки с поддержкой многострочного ввода
- ✅ **Генерация отчета** в готовом виде одним кликом
- ✅ **Копирование в буфер обмена** с уведомлением
- ✅ **Темная тема** с сохранением выбора в localStorage
- ✅ **Адаптивный дизайн** для всех устройств
- ✅ **Горячие клавиши** (Ctrl+Enter для быстрой генерации)
- ✅ **Автоматическое сохранение** введенных данных
